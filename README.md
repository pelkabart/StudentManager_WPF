# Student Manager (WPF + MVVM + SQLite)

A simple WPF desktop application for managing students.

## Features
- List students
- Search by ID / name / surname
- Add a new student
- Delete student by ID
- Data stored in SQLite (`DemoDB.db`)

## Tech stack
- C# / .NET
- WPF
- MVVM (Caliburn.Micro if used)
- SQLite (Microsoft.Data.Sqlite)

## Run
1. Clone repository
2. Open solution in Visual Studio
3. Run

The demo database file is copied automatically to the output directory.
